# 行動規範

## 私たちの約束

年齢、体格、障害、民族、gender identity・表現、経験、国籍、外見、人種、
宗教、sexual identity・orientationにかかわらず、すべての参加者に歓迎と
尊重のある環境を提供します。

## 期待される行動

- 歓迎的でinclusiveな言葉を使う。
- 異なる視点と経験を尊重する。
- 建設的な批判を誠実に受け止める。
- communityとprojectにとって最善のことへ集中する。
- 他の参加者へempathyを示す。

## 許容されない行動

- 形態を問わないharassment、intimidation、discrimination。
- trolling、侮辱、蔑視的発言、個人的・政治的攻撃。
- 公開・非公開を問わないharassment。
- 明示的許可なく他者のprivate informationを公開すること。
- professional environmentで不適切と合理的に考えられるその他の行為。

## 適用範囲

issue、pull request、discussion、関連communication channelを含むすべての
project spaceと、projectを代表してpublic spaceで行動する場合に適用します。

## 報告

問題行為を経験・目撃した場合、GitHubからmaintainerへ直接連絡します。
privateである必要がない場合はissueを利用できます。報告は速やかに確認し、
channelが許す範囲で機密に扱います。

## 執行

違反者はmaintainerの判断により警告、一時停止、永久的な参加停止の対象に
なります。本規範を遵守・執行しないmaintainerにも同じ措置が適用されます。

## 帰属

Contributor Covenant version 2.1を基にしています。
