# 利用条件

この日本語版パッケージは、
[`anthropics/claude-for-legal`](https://github.com/anthropics/claude-for-legal)
をMicrosoft 365 Copilot Cowork向けに変更した派生物です。原著作物と本
派生物には、同梱するApache License, Version 2.0が適用されます。英語版の
ライセンス本文が正式な条件です。

## 法務成果物

すべての出力はレビュー用ドラフトであり、法的助言、法的結論、適法性の
保証、署名・提出・送信・導入の承認ではありません。利用者と導入組織は、
該当法域の有資格者による確認、情報源の検証、権限、秘密保持、保持、共有先
および最終判断について責任を負います。

## Microsoft 365と第三者サービス

Microsoft 365 Copilot Cowork、SharePoint、OneDrive、Power Platform、
外部connectorおよび第三者コンテンツには、それぞれの提供者の契約条件、
利用資格、認証、データ利用条件が適用されます。本パッケージは第三者製品の
利用権、商標権、コンテンツ再配布権またはconnector利用資格を付与しません。

## 保証

Apache-2.0に定めるとおり、本パッケージは現状有姿で提供され、明示・黙示を
問わず保証されません。本番導入前に、対象テナントで検証し、組織のsecurity、
privacy、legal、records management要件を満たすことを確認してください。
