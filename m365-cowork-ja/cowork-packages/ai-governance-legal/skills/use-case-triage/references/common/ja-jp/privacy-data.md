# 日本 — 個人情報・データ

**状態:** DRAFT — qualified Japanese counsel review pending

**一次資料確認日:** 2026-07-16

## 1. 現行法を基礎にする

AIへの入力、学習、fine-tuning、RAG、ログ、評価データに個人情報または個人データが含まれる場合、個人情報の保護に関する法律、関連政令・規則、個人情報保護委員会（PPC）ガイドラインを確認する。

- 現行法: https://laws.e-gov.go.jp/law/415AC0000000057
- PPC法令・ガイドライン: https://www.ppc.go.jp/personalinfo/legal/
- 生成AI利用の注意喚起: https://www.ppc.go.jp/news/careful_information/230602_AI_utilize_alert/

「AIに使うから本人同意が不要」「公開情報だから無制限に学習できる」と一般化しない。利用目的、取得、目的外利用、第三者提供、委託、共同利用、越境、要配慮個人情報、安全管理、本人対応をデータフローごとに確認する。

## 2. 2026年改正の扱い

改正案は2026年7月10日に参議院本会議で可決され、国会で成立した。
2026年7月14日に閣議で公布が決定されたが、2026年7月16日の確認時点で
国会議案ページには公布年月日と法律番号が掲載されておらず、施行前である。
改正には統計等、16歳未満、特定生体個人情報、連絡可能個人関連情報、
課徴金等が含まれる。

- PPC法案資料: https://www.ppc.go.jp/news/press/2026/260407/
- 参議院要旨: https://www.sangiin.go.jp/japanese/joho1/kousei/gian/221/meisai/m221080221054.htm
- 参議院採決: https://www.sangiin.go.jp/japanese/touhyoulist/221/221-0710-v002.htm
- 衆議院経過: https://www.shugiin.go.jp/internet/itdb_gian.nsf/html/gian/keika/1DE26F2.htm

## 3. AIデータフロー確認

| 段階 | 必須確認 |
|---|---|
| 取得 | データ項目、取得元、本人への表示、適法性、要配慮性 |
| 入力 | 誰が何をprompt/RAGに投入できるか、秘密・個人データの許可範囲 |
| 推論 | ベンダー、処理地域、保持期間、human review、ログ |
| 学習 | 基盤モデル学習、サービス改善、fine-tuning、評価への二次利用 |
| 出力 | 個人の推測、誤り、第三者情報、再識別、意思決定への利用 |
| 共有 | 委託・第三者提供・共同利用・越境の区分と契約 |
| 削除 | 契約終了時、本人請求、誤投入、バックアップの取扱い |

## 4. 生成AIベンダー確認

- 入力・出力を学習またはサービス改善に使うか。
- opt-in / opt-outの既定値と証跡。
- 人が品質確認のため閲覧できるか。
- 保持期間、削除、バックアップ、subprocessor。
- 国外処理・保存と情報提供。
- 漏えい等の通知、調査協力、監査資料。
- 上流モデル提供者にも同等条件がflow-downされるか。

規約だけでなく、契約、DPA、AI addendum、管理画面設定、製品仕様を照合する。

## 5. AIA / PIA連携

個人データを扱う場合、AI影響評価だけで完了としない。プライバシー評価を並行し、少なくとも次を記録する。

民間事業者一般についてPIAは一律の法定義務ではないが、PPCが促進する
リスク管理手法であり、本モジュールでは内部導入条件として実施する。

- PIA促進資料: https://www.ppc.go.jp/files/pdf/pia_promotion.pdf
- PIA概要: https://www.ppc.go.jp/files/pdf/pia_overview.pdf

- 処理目的と必要性・相当性
- データ最小化
- 影響を受ける人への説明
- 異議、訂正、停止、相談
- 人による監督
- 安全管理措置
- ベンダー管理
- 残余リスクと承認者

## 6. 失敗ゲート

データ項目、利用目的、ベンダー学習条件、保存国、本人影響のいずれかが不明な場合、「個人情報なし」と仮定して進めない。必要な原資料を指定し、ドラフト結論を保留する。
