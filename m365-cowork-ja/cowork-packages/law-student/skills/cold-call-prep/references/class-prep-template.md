# 授業準備template

質問はexact assigned reading、syllabus、student notesから作ります。

## Coverage

- 法令本文、要件、趣旨
- 重要事実、手続経過、争点、結論
- 判旨と事案の射程
- 個別意見・反対論
- 前後の教材との関係
- 事実変更による適用
- policy・学説対立（指定教材にある場合）

日本の法科大学院を米国cold-call文化へ合わせず、実際の授業方法を優先します。
professor/examinerの氏名、研究分野、過去の評判から「聞かれそう」と予測しません。

## Post-drill

```markdown
STUDY NOTES — NOT LEGAL ADVICE

# 授業準備 — [course / reading / date]

**確認したsource:** [item/version/pages]
**自分で説明できた:** [項目]
**資料へ戻る:** [項目とexact section]
**未確認:** [coverage gap]
**授業前にすること:** [最大3項目]
```

このsummaryは授業への提出物、出席記録、LMS投稿ではありません。
