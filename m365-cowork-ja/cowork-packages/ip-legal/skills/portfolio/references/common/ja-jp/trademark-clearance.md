# 日本商標 — clearance、使用、取消

## Intake

- word / device / 3D / sound等のmark type
- exact characters、kana reading、kanji meaning、romaji、transliteration
- logo/device element、color claim
- goods/services、Nice class、類似群コード
- intended use、users、channels、territory、filing timing
- proposed owner、licensee、group company use

## Search

1. J-PlatPat exact、partial、phonetic、owner。
2. identical/adjacent類似群コード。Nice classを跨ぐcodeも見る。
3. pending、registered、defensive mark、relevant dead record。
4. Madrid designation affecting Japan。
5. trade name、domain、app store、marketplace、social、unregistered well-known use。
6. Japanese translation、transliteration、script variation、称呼候補。

searchしなかったsourceを「該当なし」と表示しません。Nice classまたは類似群コード
一致はconclusiveではなくsearch scope evidenceです。

## Analysis

- **[B]** Trademark Act Arts. 3, 4, 8, 19–20, 26, 32, 50。
- **[B]** UCPA well-known/famous indication、product configuration。
- **[G]** JPO Trademark Examination Guidelines、Similar Goods/Services
  Guidelines、類似群コード、Nice 13-2026。
- **[C]** *Hyozan*: appearance、sound、concept、actual trading circumstancesを
  全体として評価。

`du Pont`, `Polaroid`, `Sleekcraft`、Lanham Act、TDRAを日本testとして使いません。

## Current points

- consent制度は2024-04-01以降のapplicationに適用。pre-commencement application
  と、そのfiling dateへ遡及するdivision等は対象外となり得る。written consentだけ
  では足りず、JPOが
  likelihood of confusionなしと判断する必要があります。
- Nice Classification 13th edition, version 2026は2026-01-01適用。
- Trademark Examination Guidelinesの2026 editionは2026-04-01適用。
- registrationは10年。renewal、installment、late routeはcurrent official data確認。
- 3年間の不使用はdesignated goods/servicesの取消risk。U.S. §8/§71ではない。
- licensee conductがquality misconception/confusionを生じさせる場合、Art. 53取消を
  screenします。

## Output

- proposed mark/use/owner
- search source、query、date、coverage
- exact/phonetic/concept/script/market hits
- official-register evidenceとmarket evidenceを別表
- Art. 3/4等のregistrability flags
- *Hyozan* factor、trading circumstances
- consent/non-use/prior-use/UCPA issues
- `no conclusion — Japanese trademark counsel review required`

「GREEN」または「clear」は正式clearance opinionを意味しません。search未実施なら
no-search statementを明示し、full professional searchを次stepにします。
